# Personal Expense Tracker

A full-stack web application that allows users to track their personal expenses securely using their Google account and Google Sheets as the database.

## 🚀 Features
*   **Secure Authentication:** Sign in using Google OAuth 2.0.
*   **Database Integration:** Automatically creates and manages a Google Sheet to store expenses, or links to an existing one.
*   **CRUD Operations:** Add, view, edit, and delete expenses securely from the UI.
*   **Analytics:** View total expenses categorized by type and a simple current-month summary.

## 🛠 Tools & Technologies Used
*   **Frontend:** HTML5, CSS3, Vanilla JavaScript
*   **Backend:** Node.js, Express.js
*   **APIs:** Google Sheets API v4, Google Identity Services
